# VEML-7700: Visible Light Intensity

# Introduction

The VEML-7700 is a sensitive and accurate visible light sensor, detecting ambient light using a photodiode, which absorbs light radiation and converts it to electricity — the exact reverse of a light-emitting diode (LED)! The sensor has a 16 bit dynamic range of 0 lux to 140 klux and resolution to 0.0042 lx/ct, where lux is the unit of light intensity per unit area.
